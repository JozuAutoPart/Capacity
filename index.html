ระบบแจ้งซ่อมและจัดการแม่พิมพ์ (Mold Maintenance System)
Architecture Implementation & Ready-to-Use Code Guide (GitHub + Apps Script + Dashboard)

เอกสารฉบับนี้รวบรวม **Code สำหรับการติดตั้งระบบแจ้งซ่อมแม่พิมพ์ (PM & Breakdown)** ผ่านมือถือ โดยเชื่อมต่อระหว่าง **Google Forms / Google Apps Script**, **GitHub API (Issue & Project)** และ **Looker Studio Dashboard** ครบถ้วนพร้อมใช้งาน

1. โครงสร้างระบบและการทำงาน (System Architecture)

องค์ประกอบ เทคโนโลยีที่ใช้ หน้าที่การทำงาน
1. Frontend (Mobile) Google Forms / QR Code รับข้อมูลการแจ้งซ่อม PM หรือ Breakdown จากหน้างานด้วยมือถือ
2. Middleware Integration Google Apps Script แปลงข้อมูลจาก Google Form เป็น JSON และยิงผ่าน GitHub API เพื่อสร้าง Issue อัตโนมัติ
3. Backend & Tracking GitHub Issues & Projects เก็บบันทึกประวัติการซ่อม ติดตามสถานะ (Kanban) มอบหมายช่าง และคอมเมนต์รูปภาพ/อะไหล่
4. Analytics & Dashboard Looker Studio / BigQuery ดึงข้อมูลประวัติการซ่อมมาประมวลผลเป็น KPI (MTTR, Breakdown Rate, Top Repeat Defects)

2. โครงสร้าง Issue Templates บน GitHub

สร้างไฟล์ Template สองไฟล์ไว้ที่ไดเรกทอรี .github/ISSUE_TEMPLATE/ ใน GitHub Repository ของคุณ เพื่อกำหนดโครงสร้างข้อมูลมาตรฐาน

3. Google Apps Script Code (เชื่อมต่อ Google Form เข้า GitHub)

นำซอร์สโค้ดด้านล่างนี้ไปใส่ใน Google Form ➔ Extensions ➔ Apps Script เพื่อส่งข้อมูลเข้า GitHub Issues โดยอัตโนมัติเมื่อพนักงานกด Submit Form

// ===== CONFIGURATION =====
const GITHUB_TOKEN = "ghp_YOUR_PERSONAL_ACCESS_TOKEN_HERE"; // แทนที่ด้วย Personal Access Token ของคุณ
const REPO_OWNER = "YOUR_GITHUB_USERNAME_OR_ORG";            // ชื่อ User หรือ Organization ใน GitHub
const REPO_NAME = "YOUR_REPO_NAME";                           // ชื่อ Repository เช่น mold-maintenance

function onFormSubmit(e) {
  const itemResponses = e.response.getItemResponses();
  
  let workType = "";
  let moldCode = "";
  let partName = "";
  let details = "";
  let lineStop = "";
  let reporter = e.response.getRespondentEmail() || "ผู้แจ้งหน้างาน";

  // วนลูปอ่านค่าตามชื่อหัวข้อใน Google Form
  for (let i = 0; i < itemResponses.length; i++) {
    const title = itemResponses[i].getItem().getTitle();
    const response = itemResponses[i].getResponse();

    if (title.includes("ประเภทงาน")) workType = response; // PM หรือ Breakdown
    if (title.includes("รหัสแม่พิมพ์")) moldCode = response;
    if (title.includes("ชื่อชิ้นงาน")) partName = response;
    if (title.includes("รายละเอียด")) details = response;
    if (title.includes("หยุดการผลิต")) lineStop = response;
  }

  // กำหนด Title และ Labels ตามประเภทงาน
  let issueTitle = "";
  let labels = [];
  
  if (workType.includes("Breakdown")) {
    issueTitle = `[Breakdown] ${moldCode} - ${details.substring(0, 30)}`;
    labels = ["type: breakdown"];
    if (lineStop.includes("ใช่") || lineStop.includes("หยุดไลน์")) {
      labels.push("priority: line-stop");
    }
  } else {
    issueTitle = `[PM] ${moldCode} - บำรุงรักษาตามรอบ`;
    labels = ["type: pm"];
  }

  // สร้าง Body เนื้อหาใน Issue
  let bodyMarkdown = `## 📌 รายงานการแจ้งงาน (${workType})\n`;
  bodyMarkdown += `* **รหัสแม่พิมพ์:** ${moldCode}\n`;
  bodyMarkdown += `* **ชื่อชิ้นงาน:** ${partName}\n`;
  bodyMarkdown += `* **ผู้แจ้งเรื่อง:** ${reporter}\n`;
  bodyMarkdown += `* **รายละเอียด/อาการ:**\n${details}\n\n`;
  bodyMarkdown += `---\n*แจ้งเรื่องผ่านระบบ Mobile Form*`;

  // เรียกใช้ GitHub API
  createGitHubIssue(issueTitle, bodyMarkdown, labels);
}

function createGitHubIssue(title, body, labels) {
  const url = `https://script.google.com/macros/s/AKfycbzQBXdSHpcCXa5hM2asS-9w1xEwXVoPuuRUHCsjNR1k9zEKCdILqT8OslxxWsJsLVV0/exec`;
  
  const payload = {
    "title": title,
    "body": body,
    "labels": labels
  };

  const options = {
    "method": "post",
    "contentType": "application/json",
    "headers": {
      "Authorization": "token " + GITHUB_TOKEN,
      "Accept": "application/vnd.github.v3+json"
    },
    "payload": JSON.stringify(payload),
    "muteHttpExceptions": true
  };

  const response = UrlFetchApp.fetch(url, options);
  Logger.log("GitHub API Response: " + response.getContentText());
}
💡 วิธีตั้งค่า Trigger ใน Google Apps Script
  1. ไปที่แถบเมนูด้านซ้าย เลือกไอคอนรูปนาฬิกา (Triggers)
  2. กด + Add Trigger
  3. เลือกฟังก์ชัน: onFormSubmit
  4. เลือก Event type: On form submit แล้วกด Save

4. การออกแบบ Looker Studio Dashboard (PM vs Breakdown Analysis)

เพื่อนำข้อมูลมาแสดงวิเคราะห์ผ่าน Dashboard ให้เชื่อมต่อ GitHub Data เข้ากับ Looker Studio (ผ่าน GitHub REST API / Google Sheets Sync)

📊 รายการ metrics และวิทเจ็ตที่แนะนำสำหรับ Dashboard

องค์ประกอบ Dashboard รูปแบบที่แนะนำ สูตรคำนวณ / ฟิลด์ข้อมูล
1. Ratio PM vs Breakdown Donut Chart เปรียบเทียบสัดส่วนระหว่าง Label type: pm และ type: breakdown (เป้าหมาย PM ≥ 70%)
2. MTTR (Mean Time To Repair) Scorecard Metric AVG(Closed Date - Created Date) สำหรับงาน Breakdown
3. Top 5 Repeat Defects Bar Chart นับจำนวน Issue แยกรายแม่พิมพ์ (ช่วยกรองหาแม่พิมพ์ที่มีปัญหาบ่อย)
4. Line-Stop Incidents KPI Card (Red Highlight) นับจำนวน Issue ที่มี Label priority: line-stop
5. Live Work Tracking Table with Status Badges ตารางสรุปงานปัจจุบัน: Mold Code | Issue Title | Assignee | Status (Open/In Progress/Closed)
